# Nomad - Entrega 9

Entrega: SEO y Servidores.

## Mejoras realizadas

- Título SEO único para cada una de las 5 páginas.
- `meta description` específica en cada HTML.
- `meta keywords` acorde al contenido de cada página.
- `meta robots` y URL canónica.
- Jerarquía semántica mantenida con un solo `h1` por página.
- Textos `alt` descriptivos en las imágenes.
- Revisión de etiquetas semánticas: `nav`, `main`, `section`, `article` y `footer`.
- `robots.txt` para buscadores.
- `sitemap.xml` con las cinco URLs públicas.
- Se conserva el responsive, las animaciones y la arquitectura SCSS de los módulos anteriores.

## Compilación de SCSS

```bash
npm install
npx sass scss/main.scss css/style.css
```
